Welcome to CleanNet

Before CleanNet changes Windows proxy settings, review what will happen and start it yourself.

Runs only on this computerCleanNet runs locally on your computer. It listens on 127.0.0.1, stores settings in one visible folder, and only enables the Windows user proxy after you confirm this setup.
Proxy with your consentWindows proxy stays off until you press Start CleanNet. You can reset it from tray or dashboard.
Data folder--

Starting CleanNet writes only user-level Windows proxy settings. It does not install drivers, services, certificates or system-wide hooks.
